# Projeto de Análise de Dados - Previsão de Churn (Semantix & EBAC)

Este repositório contém a entrega final do projeto prático de Análise de Dados desenvolvido em parceria entre a EBAC e a Semantix. O objetivo principal é prever e analisar o *Churn* (taxa de cancelamento de clientes) utilizando uma base de dados pública de telecomunicações.

## Tecnologias e Ferramentas Utilizadas
* **Python (Google Colab):** Utilizado para a limpeza dos dados, Análise Exploratória de Dados (EDA) e treino do modelo de Machine Learning (Árvore de Decisão).
* **Google Data Studio:** Utilizado para a criação do dashboard executivo interativo.
* **Google Docs / PDF:** Utilizado para a elaboração da documentação teórica e relatório de insights.

## Estrutura do Repositório
* `Projeto de Analise de Dados - Semantix.pdf`: Documento completo contendo todas as etapas do projeto (Dissertação do Problema, Fontes de Dados, EDA, Relatório de Insights e Autorização LGPD).
* `analise_churn_model.ipynb`: Ficheiro de código fonte executado no Google Colab com a limpeza de dados e o modelo de Machine Learning (Árvore de Decisão).
* `Análise_de_Risco_de_Cancelamento.pdf`: Painel interativo online desenvolvido para a visualização dinâmica dos principais indicadores de *Churn*, taxas de cancelamento por tipo de contrato e curvas de evasão temporal.
